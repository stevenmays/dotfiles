# Why each rule exists

Read this only when a situation isn't covered by `SKILL.md` and you need the reason behind a rule to decide. Page numbers refer to _The Math Academy Way_ (Skycak, working draft updated 2026-08-13). Other sources are named by author and year.

## The core loop

| Rule                                                              | Reason                                                                                                                                                        | Source                           |
| ----------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------- | -------------------------------- |
| Quiz, drill to criterion, re-quiz, then relearn in later sessions | Retrieving to a criterion in each session, repeated across spaced sessions, gives durable retention at a low time cost. This is called successive relearning. | Rawson and Dunlosky 2011         |
| Review by testing, never by rereading                             | Practice testing and spaced practice rank highest among study methods. Rereading, highlighting, and summarizing rank lowest.                                  | p. 148-149; Dunlosky et al. 2013 |
| Spend most turns on problems                                      | Explanation isn't the bottleneck. The time goes to problems, mixed quizzes, remedial reviews, and spaced review.                                              | p. 465-466                       |
| Short, complete explanation before practice | Learners solve problems within minutes of a minimum effective dose of explanation. A lesson holds about 7 active problems per worked example. | p. 176, 182, 398 |
| Take the learner's questions before practice | Active learning with direct instruction beats both unguided practice and passive listening. A question asked before practice surfaces confusion before it turns into wrong answers. | p. 190 |
| Direct instruction before practice                                | For novices, guided instruction beats discovery. A learner who discovers a wrong idea tends to recall the discovery instead of the correction.                | p. 140-146, 190                  |
| Teach first; plan without asking | The learner came to learn. A setup question before teaching delays the first win and asks for an answer the tutor can choose itself. The learner can redirect the goal at any time. | Learner feedback on this skill |

## The lesson page

| Rule | Reason | Source |
| ---- | ------ | ------ |
| 1 page per topic, read 1 section at a time | Learners do better when they pace a lesson in segments. Section numbers match the map, so chat points at 1 segment at a time. | Mayer 2009 (segmenting) |
| The overview names every knowledge point before section 1 | Learners do better when they know the names and roles of the main concepts before the details. | Mayer 2009 (pre-training) |
| Text beside its diagram, 1 color per concept | Words next to the picture they describe, and cues that mark the structure, cut search and load. | Mayer 2009 (spatial contiguity, signaling) |
| No decoration or extra facts | Interesting but extraneous material lowers learning. | Mayer 2009 (coherence) |
| 1 live widget per knowledge point | A widget turns 1 worked example into many varied examples the learner picks, which helps them abstract the rule. | Gentner, Loewenstein, and Thompson 2003; Fyfe et al. 2014 |
| The page explains, chat practices | Difficulty eats the working memory that understanding needs, so the page removes friction. During retrieval, difficulty is the tool, so graded practice happens in chat. | Pocock, `teach` skill; Bjork 1994 |
| Grading stays in chat | The ledger logs only graded answers, and a page quiz lets the learner recognize instead of recall. | Slamecka and Graf 1978 |

## Working memory

| Rule                                        | Reason                                                                                                                                                                    | Source                                              |
| ------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | --------------------------------------------------- |
| 1 question and 1 new idea per message       | Working memory holds about 4 chunks for about 20 seconds, and fewer while manipulating them. Heavy load raises errors even on tasks within capacity.                      | p. 56, 226-227; Cowan 2001                          |
| Self-contained questions                    | Scrolling back to find a value holds that value in working memory while the learner solves the problem.                                                                   | p. 56                                               |
| Write intermediate values down              | Writing a result down reloads working memory. "When in doubt, write it out."                                                                                              | p. 59-61, 424-426                                   |
| Drill component steps to fluency            | An automatic skill uses no working memory slot, which frees capacity for the new part of a problem. Knowledge in long-term memory acts as an extension of working memory. | p. 111, 225-228                                     |
| State the rule and vary the examples        | Learners tend to memorize example details instead of abstracting the rule. Comparing varied examples helps learners extract the rule.                 | p. 108-109; Gentner, Loewenstein, and Thompson 2003 |
| Labeled steps in worked examples            | Subgoal labels group steps into named chunks, which cuts load and helps transfer.                                                                                         | p. 219; Catrambone 1998                             |
| Practice steps alone before the whole       | Splitting a complex problem into parts that each use 1 learned skill keeps load inside capacity.                                                                          | p. 218; Pollock, Chandler, and Sweller 2002         |
| Remove support as skill grows               | Scaffolding that helps a novice slows an expert, so later reviews mix types and drop the cues.                                                                            | p. 222-223; Kalyuga et al. 2003                     |

## Mastery and gaps

| Rule                                       | Reason                                                                                                                                                                                                       | Source                           |
| ------------------------------------------ | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ | -------------------------------- |
| 3 to 4 knowledge points per topic          | Topics split into 3 to 4 knowledge points of rising difficulty, each with a worked example and 2 to 5 questions.                                                                                             | p. 217, 397                      |
| 2 correct in a row at the end of practice  | Order matters: misses followed by correct answers show learning, and correct answers followed by misses show it didn't stick.                                                                                | p. 414                           |
| Teach before testing; test out on request | A learner can't retrieve what they never learned, so a quiz on untaught material yields "no idea" answers that carry no data and cost motivation. Learners are 3 to 4 times as likely to master a topic on their knowledge frontier as one beyond it, so `test out` still finds the frontier when the learner already knows part of a topic. A gap begets more gaps. | p. 127, 212 |
| Never accept "I know this"                 | Self-reports overestimate knowledge.                                                                                                                                                                         | p. 446, 463                      |
| A test-out answer credits prerequisites | A correct answer credits what it builds on. A wrong answer puts what builds on it in doubt. The best test-out question is the simplest one that would convince an expert and exercises every prerequisite. | p. 375-381 |
| Ask for a best guess in quizzes | Guesses from unsure learners are often right, and a guess gives better data than "I don't know". | p. 462-467 |
| Stop re-explaining after 5 misses          | Re-explaining many ways hides a missing prerequisite. Probe the key prerequisite, or pause and return later. 80% of paused lessons pass on return.                                                           | p. 300-301, 416-418              |
| Shaky correct answers count as gaps        | Familiarity isn't knowledge, and nobody can build on familiarity. Treat a low-confidence correct answer like a miss and retry it the next day.                                                               | p. 229, 427, 450-451             |
| Follow up on silly mistakes                | Errors compound, and many careless errors hide a conceptual gap.                                                                                                                                             | p. 152                           |
| Drill confident misses first               | Errors made with high confidence are corrected more readily than low-confidence errors once feedback contradicts them.                                                                                       | Butterfield and Metcalfe 2001    |
| The learner names the error and reworks it | Explaining a solution to yourself improves learning. Under-reliance on worked solutions is a warning sign.                                                                                                   | p. 338, 401-402; Chi et al. 1989 |
| Free recall over multiple choice           | Generating an answer builds stronger memory than recognizing one.                                                                                                                                            | Slamecka and Graf 1978           |

## Spacing, mixing, and interference

| Rule                                                | Reason                                                                                                                                                                                                           | Source                                  |
| --------------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | --------------------------------------- |
| Expanding intervals                                 | Each successful review at the right time lengthens the next interval, from 1 day to weeks to years. The intervals in `ledger.py` use Anki's SM-2 defaults, because the book publishes structure but no formulas. | p. 252, 266, 372-373                    |
| A solid gives credit to due prerequisites           | Practicing an advanced skill also practices the skills it contains. Math Academy calls this fractional implicit repetition.                                                                                      | p. 241, 364-367                         |
| No implicit credit for weak knowledge points | Learners who struggle on a topic absorb implicit practice poorly, so those topics get explicit reviews only. `ledger.py` also withholds credit until a knowledge point passes 1 review of its own, and after a shaky or missed answer. | p. 263-264 |
| A miss pulls the dependent knowledge points forward | A failure on a simple skill puts the advanced skills that contain it in doubt. Penalties flow up the graph.                                                                                                      | p. 364                                  |
| Prefer questions that cover several due items       | Choosing reviews whose implicit credit covers the most due topics compresses review time.                                                                                                                        | p. 261-262, 369                         |
| Block in lessons, mix in quizzes                    | A small dose of blocked practice suits a lesson. Reviews and quizzes interleave, which trains the learner to match a problem to its technique. Interleaving doubled test scores in 1 study.                      | p. 271-279, 415; Rohrer and Taylor 2007 |
| Several questions for a weak knowledge point        | Multiple questions test consistency and resist guessing.                                                                                                                                                         | p. 413                                  |
| Space confusable knowledge points 3 days apart      | Teaching related ideas close together causes interference. A 3-day gap markedly reduced it.                                                                                                                      | p. 247-249                              |
| Reviews feel hard                                   | Only effortful retrieval extends retention. Learners in active classes believe they learned less while they learned more.                                                                                        | p. 184, 407-408; Bjork 1994             |
| Aim for about 85% accuracy                          | Practice difficulty targets 80% to 85% accuracy. At that rate, about 5 confirmations land per correction.                                                                                                        | p. 343, 404; Wilson et al. 2019         |

## Coaching and habit

| Rule                        | Reason                                                                                                                                              | Source                                         |
| --------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------- | ---------------------------------------------- |
| Specific praise             | Praise works when it's accurate, specific, and about strategy. Effusive praise marks the least effective tutors.                                    | p. 339-343                                     |
| No notes during quizzes     | A reference loads only short-term memory. Solving alongside a reference produces excess forgetting.                                                 | p. 337, 412, 423-427                           |
| 20 to 40 minutes, most days | 30 minutes on 6 days beats 90 minutes on 2. Under about 20 minutes, the cost of switching context dominates.                                        | p. 436-441                                     |
| Fixed time and place        | Habit predicts behavior better than intention. A plan that names when and where works as an instant habit. Habits take a median of 66 days to form. | p. 345-352; Gollwitzer 1999; Lally et al. 2010 |
| Default to an in-chat progress card in claude.ai | 1 chat already holds the history, and a file the learner must attach and download costs steps every session. The card records dates, because chat messages carry no timestamps the tutor can read. | Learner feedback on this skill |
| Concrete before abstract    | Concrete procedures come before abstraction and derivation.                                                                                         | p. 452-454; Fyfe et al. 2014                   |

## The plan step

The plan step doesn't come from the book. It runs silently: the tutor answers its 4 questions without asking the learner. The step asks what a top practitioner would learn, which primary source they would start from, which tools they would use, and which outside check would show an answer is right. The closest rule in the book is that lessons cover every problem type a learner could reasonably be expected to solve (p. 243). The outside check also catches the tutor's own grading mistakes, because a model can grade a wrong answer as right.

## What chat can't do

- Time answers. The confidence rating stands in for speed.
- Stop the learner from checking notes. The skill relies on self-report.
- Send reminders. The learner's fixed session time carries the schedule.
- Calibrate against other learners. The per-knowledge-point ease in `ledger.py` adapts to this learner only.
